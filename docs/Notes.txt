SUBTITLE DESK 1.1.0 — RELEASE NOTES

Purpose
-------
An offline native desktop editor for turning audio/video files into timed
subtitles and lyric lines, then reviewing and correcting the result by ear.

New in 1.1.0
------------
* Use Models... beside the selector, or View > Models..., to install your
  own compatible whisper.cpp GGML .bin or Whistle .cact audio models.
* Import copies the source into application data, verifies its structure,
  hashes its content, and checks it with the bundled recognizer. Progress
  and cancellation remain available. Your original file is unchanged.
* Maximum file size: 8 GiB. Engine load validation: up to five minutes.
  Larger models need more memory and CPU time. No format conversion or
  automatic download is provided. Archives, PyTorch, Safetensors, and
  general-purpose GGUF/LLM files are not supported.
* English-only Whisper models offer Auto/English. Whistle continues to
  offer its seven languages. Existing bundled models remain available.
* Duplicate content reuses the installed model. Remove imported copies
  through the manager; bundled and actively used models are protected.
* Projects refer to a model by content ID and do not embed weights. A
  missing model must be installed or replaced before transcribing, while
  existing subtitle text and timing stay editable.

Included
--------
* Four bundled CPU recognition choices: Cactus Whistle, Whisper Tiny,
  Whisper Base, and Whisper Small. Whisper models are multilingual Q5_1.
* Audio-only import from common media containers; no video display.
* Waveform seeking; 0.5x–2x playback; active-cue highlighting; cue replay
  and looping without moving the user's text-editing selection.
* Editable start/end times and text; playhead boundary controls; add,
  split, merge, delete, shift, undo/redo, search, and review marks.
* Timing/readability checks and periodic unsaved-project recovery.
* SRT, WebVTT, ASS, LRC, TXT, CSV, JSON exports and .sdesk projects.
* System, Light, and Dark themes; 680 x 540 minimum window.

Format and recognition details
------------------------------
* Original media is not changed. Projects link to media; they do not
  embed it. Keep the original file available or relink it from File.
* Decoding retains audio offsets and gaps relative to the container's
  playback origin. Sources without timestamps use continuous sample timing.
  Tracks exceeding the PCM processing limit (about 37 hours) must be split.
* SRT/VTT/CSV/JSON preserve millisecond timing. ASS and LRC use
  centiseconds. LRC has starts only, so imported ends are inferred.
* CSV neutralizes spreadsheet formula prefixes; project text is unchanged.
* Whistle provides recognized word timing and supports English, German,
  French, Spanish, Italian, Dutch, and Polish. Whisper provides segment
  timing and broader multilingual recognition. All timings are estimates.
* Singing and music can reduce recognition accuracy. Review the words and
  cue boundaries. LRC output is line-timed; automatic karaoke alignment
  and speaker diarization are not provided.
* The first audio stream is used. There is no audio-track selector.
* Imported formatting/effects become plain text. ASS exports use one
  neutral style. See README.html for precise format behavior.

Storage
-------
Settings, recovery, and imported models use %AppData%\SubtitleDesk on Windows and
~/.config/SubtitleDesk on Linux (respecting XDG_CONFIG_HOME). An empty
portable.flag beside the executable switches them to its writable data
subfolder. Imported weights are in models/ within that location.
Temporary review audio is cleaned up when the session ends normally. Exporting subtitles does not
replace saving an editable project.
